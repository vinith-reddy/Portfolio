Featured Project

Carbon-EF: Knowledge Graph-based Emission Factor System

AI/ML Knowledge Graph RAG Sustainability

A sophisticated system for real-time, region-specific emission factor recommendations using knowledge graphs, vector search, and large language models. The system achieves ~150ms end-to-end latency and covers 44+ regions with 87.2% precision.

My Role: Data collection from multiple sources, model fine-tuning, and implementing graph RAG pipeline
Tech Stack: Python, Neo4j, Qdrant, Mistral-7B, Streamlit, Plotly
Data Sources: IPCC AR6, EXIOBASE 3.8, OpenLCA, Climate TRACE
Performance: 87.2% Precision@3, 4.8% MAPE, ~150ms latency
